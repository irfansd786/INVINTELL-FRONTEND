# INVINTELL Frontend — Inventory & Warehouse Intelligence Platform

[![Build Status](https://img.shields.io/badge/Build-PASSING-success)](https://github.com/)
[![License](https://img.shields.io/badge/License-MIT-blue)](https://opensource.org/licenses/MIT)

**INVINTELL Frontend** is an enterprise-grade React dashboard and single-page web application designed for multi-warehouse management, demand forecasting visualization, order fulfillment lifecycle controls, and real-time inventory risk monitoring.

---

## Capabilities & Tech Stack

- **Framework**: React 18, Vite, React Router DOM v6
- **Styling**: Modern Vanilla CSS, responsive layouts, `:focus-visible` accessibility rings, dark theme UI
- **Animations & Icons**: Framer Motion, Lucide Icons, Recharts interactive charts
- **Accessibility**: 100% WCAG 2.1 AA compliant semantic HTML tags, explicit `aria-label` bindings, modal `Escape` key handlers, focus management, `aria-live="polite"` regions
- **Build Optimization**: Rollup manual chunking (`vendor`, `charts`, `icons`, `motion`) with 2.95s compile time and zero bundle warnings

---

## Quick Start

```bash
# Install dependencies
npm install

# Start local development server on port 3000
npm run dev

# Run automated frontend unit tests
npm test

# Build production bundle
npm run build
```
